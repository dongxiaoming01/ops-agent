# 告警分析技能

## 适用场景

当用户要求分析告警、判断告警风险、定位异常原因或生成处置建议时使用本技能。

## 执行流程

1. 从用户消息中识别告警 ID、告警对象等信息。
2. 使用已注册的监控工具查询告警详情。
3. 根据告警类型，查询相关监控指标及历史数据。
4. 综合分析告警现象、变化趋势和可能原因。
5. 给出风险等级、原因分析、处置建议及判断依据。

## 分析要求

- 只依据工具返回的数据和用户提供的信息进行判断。
- 缺少关键数据时，明确指出信息缺口，不得编造监控结果。
- 区分已确认事实与推测原因。
- 输出风险等级：LOW、MEDIUM、HIGH 或 CRITICAL。
- 优先给出可验证、可执行的排查建议。

## 执行安全

- 本技能只负责分析和提出建议。
- 未经用户明确确认，不得执行重启、清理文件、变更配置等有实际影响的操作。
- 涉及高风险操作时，必须先向用户展示操作内容和影响范围。
